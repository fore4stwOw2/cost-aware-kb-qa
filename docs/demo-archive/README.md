# 演示存档（demo-archive）· 离线兜底

> 用途：现场演示时若实时链路（API）不可用或超时，用本目录的存档截图/轨迹继续讲解，**不冒充实时结果**。
> 生成方式：`bash scripts/demo_path.sh --archive`（自动把每条路径输出写入 `traces/`，带时间戳）。

## 目录结构

```
demo-archive/
├── README.md          # 本文件：兜底说明与话术
└── traces/            # 每次 --archive 运行生成的轨迹文本
    └── <时间戳>-<路径名>.txt
```

## 何时用存档

| 现场情况 | 处理方式 |
|----------|----------|
| API 正常 | 走实时演示，存档仅作备份 |
| API 超时/限流/网络断开 | 打开对应 `traces/` 存档，说："实时链路此刻不可用，这是同一批固定输入在评测环境跑出的结果" |
| 单条路径失败 | 只讲成功路径，失败路径展示存档 + 说明边界 |

## 离线兜底话术（背下来）

> "我现在用的评测环境 API 偶尔会慢/超时——为了不浪费大家时间，这条路径我用预跑存档展示。输入是固定的，结果可复现，存档文件也在仓库里，你可以随时自己重跑验证。"

**诚实原则**（wiki 作品集指南）：存档 = 回放，标注"非实时"；不把截图说成"刚才实时跑的"。

## 已知边界

- 存档内容依赖 API 响应，不同时段重跑结果可能有文字差异（价格等数字以知识库语料为准）
- 2026-09-02 夜间网络环境下实测：单条 API 调用最长挂起 1000s+，已加三层超时（socket/client/脚本 killpg）保证演示不无限等待
