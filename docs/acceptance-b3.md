## 关键发现（badcase，B4 修复候选）

**规划器过度搜索 kb.search 不收敛**：a09/a10/a11/b04 在复杂任务中反复调用 kb.search 4-8 次，8 轮预算触顶 blocked——规划提示词缺"检索到足够信息即停止"的收敛约束。这是 Agent 独有的失败模式（单轮问答不存在），已记入 problem-log，B4 修复候选：planner 提示词加收敛规则 / kb.search 加 session 内去重。
