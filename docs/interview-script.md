# 九步面试讲解稿 · 作品二（Cost-Aware KB-QA）

> 用途：面试现场按此顺序讲解，每步给出"讲什么"和"被追问怎么答"。总时长建议 3-5 分钟讲完九步，被追问再展开。
> 配套：GitHub 仓库 `cost-aware-kb-qa`（README 是叙事页），数据全部可溯源到 `docs/`。

---

## 第一步 · 一句话（30 秒）

> "我做了一个成本感知的知识库问答应用：先判断问题难度，简单问题走便宜模型、复杂问题走贵模型，用一套 30 条的评测集证明——相比全用旗舰模型，省了 37.6% 成本，回答质量几乎不降，而且零瞎编。"

**追问预案**：为什么做成本方向？→ "我在 API 中转公司工作，每天看到客户最纠结的就是模型性价比，这个问题是我工作的真实观察。"

## 第二步 · 问题（1 分钟）

> "中小企业想给产品手册/FAQ 接一个 AI 问答，普遍三难：全用旗舰模型效果稳但账单吓人；全用便宜模型复杂问题答不好；而'路由到底能省多少、质量损失多少'，市面上没有工具能先验证。"

**追问预案**：为什么不用现成方案？→ "现成的路由方案要么是黑盒（说不清省多少），要么绑死某个平台。我的目标是把它做成可验证的数字——这也是我整个项目的方法论：一切结论用评测说话。"

## 第三步 · Demo（1 分钟，现场或存档）

> "演示五条路径：简单题走便宜档（显示路由理由和成本）、复杂题走贵档、库外题拒答不花一分钱、越权攻击被确定性拦截、断掉便宜模型自动降级到贵档并标注'降级运行'。"

**追问预案**：演示失败/API 挂了？→ 切存档轨迹（`docs/demo-archive/`），说："实时链路此刻不可用，这是同一批固定输入在评测环境跑出的结果，可复现。"

## 第四步 · 方案（30 秒）

> "技术链路：检索 top-5 带引用 → 便宜模型做三维分类（难度/可答性/理由）→ 路由到双档 → 生成后展示成本。关键设计：查询改写修召回（'27 万'→'27.2 万'匹配语料）、越权用确定性规则拦截不靠模型碰运气、故障降级链。"

**追问预案**：为什么不用 LangChain？→ "这个规模轻量自研更可控，我能讲清每个环节；LangChain 适合需要快速换链路组件的场景，我知道它解决什么问题。"

## 第五步 · 证据（1 分钟，核心）

> "30 条评测集（21 典型/6 边界/3 对抗），三臂对比：全便宜/全贵/路由。结果：路由省 37.6% 成本；路由准确率 96.3%；库外拒答 100%；三臂零瞎编；知识库内质量分 4.63 vs 全贵 4.77（5 分制差 0.14，几乎持平）。价格核验到 2026-09-01，温度=0，可复现。"

**追问预案**：LLM-as-Judge 可信吗？→ "我迭代了 4 版校准：v1 连坐误杀（人工抽查 4/4 误判）→ v2 只看答案要点误判 → v3 只看 grounded 无区分度 → v4 对照引用片段+答案要点四维判定，三个构造用例（正确/瞎编/答非所问）全部判对。裁判分数不直接采信，人工抽查过。"

## 第六步 · 取舍（30 秒）

> "最关键的取舍：路由用'规则+便宜分类器'而不是一刀切阈值。因为相似度 ≠ 可答性——有题目检索得分 0.55 但其实不可答，纯阈值拦不住。所以把可答性判断交给分类器，阈值只当免费兜底。"

**追问预案**：被放弃的方案？→ "接第二家服务商做真降级（成本/复杂度不划算，同厂降级已够演示）、微调小模型（收益不划算）、套 LangChain（讲不清环节）。"

## 第七步 · 边界（30 秒）

> "30 条是探索级评测不代表线上；降级只覆盖单模型不可用，同厂两档同时挂的概率存在；语料是公开文档、零公司内部数据；这是个人验证原型，不是生产系统。"

**追问预案**：为什么不接真实数据？→ "作品集的合规红线：演示和评测只用公开材料，避免任何公司数据风险；这也符合国内 GenAI 监管对数据来源可说明的要求。"

## 第八步 · 下一步（30 秒）

> "二期做 Agent：把检索变成工具，加确认闸门和轨迹评测，从'回答哪个模型划算'进化到'帮我测算并给出选型报告'。方法论不变：评测驱动、边界先行、一切可核验。"

**追问预案**：Agent 和现在的区别？→ "现在是单轮问答，Agent 是多步骤任务——规划、调工具、确认、完成证据，评测也从回答质量升级到轨迹评测。"

## 第九步 · 收尾一句话

> "总结：这个项目证明我能把'效果、成本、边界'放到同一套取舍里，并且用评测和文档让每个结论可被验证。"

## 附：被追问高频问题速答

| 追问 | 速答 |
|------|------|
| 评测集怎么建的？ | 30 条 70/20/10（典型/边界/对抗），覆盖价格/成本/选型/术语/库外/越权六类，每条带金标准字段 |
| 路由分类器为什么用便宜模型？ | 单次约 $0.0001，是路由里可忽略的固定开销 |
| 成本怎么算的？ | 输入/输出 token 分别乘单价（官方定价页核验，2026-09-01），含分类器开销，三臂 30 题总成本对比 |
| 最难的 bug？ | 检索召回："27 万"与语料"27.2 万"字面不匹配导致答案在库却答不出，用查询改写修复——先归因（是检索不是模型）再修 |
| 越权怎么防的？ | 确定性关键词组合拦截（攻击目标词+获取动词），不靠分类器碰运气；安全红线不能依赖概率 |
