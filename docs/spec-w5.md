# W5 需求简报 + 验收标准（演示稳定化 · v0.5.0）

> ai-native-dev-flow 第 0-2 步产物。目标：让作品二现场演示可复现、可兜底，不再依赖"这次 API 恰好正常"。
> 对应版本：v0.5.0 ｜ 分支：feat/w5-demo-stabilize

## 需求简报

- **目标**：把"能跑"变成"演示稳定"——固定演示路径可一键复现，API 异常时有离线兜底，提示词独立成库可审计。
- **范围内**：
  1. `scripts/demo_path.sh`：一键走完五条固定演示路径（简单→便宜档 / 复杂→贵档 / 库外拒答 / 越权拦截 / 断模型降级），每条输出预期行为标注
  2. `docs/demo-archive/`：关键路径截图 + 轨迹存档（固定输入、跑 3 次留证据）+ 离线兜底话术说明
  3. `docs/prompt-library.md`：提示词库独立成文（分类器/回答模型/拒答/降级，每条带版本与变更记录）
  4. README 已知边界补充（API 波动时的备用路径说明）
- **范围外**：不做公网部署（ASSUMED，演示走本地 + 截图存档）；不做新功能；不改核心管线
- **决策记录**：
  - `ASSUMED` 演示形态 = 本地一键演示 + 截图/轨迹存档，不做公网部署（公网需注册授权、国内访问不稳；wiki 允许"备用路径=截图/轨迹"）
  - `CONFIRMED` 演示路径沿用已验收的 W2/W4 行为（五条路径均有对应 AC 证据）

## 验收标准

| # | 标准（独立可判定） |
|---|------|
| AC1 | `scripts/demo_path.sh` 存在且可执行：运行后五条路径全部跑通，输出含预期行为标注（如"→便宜档""→拒答""→⚠️降级运行"） |
| AC2 | `docs/demo-archive/` 存在：含每条路径至少 1 份轨迹文本存档（固定输入运行结果）+ 离线兜底话术说明（"实时链路不可用→展示截图"的话术模板） |
| AC3 | `docs/prompt-library.md` 存在：含 4 类提示词（分类器/回答/拒答/降级），每条带版本号 v1 与变更记录（含对应代码位置） |
| AC4 | 断网/API 异常模拟（`OPENAI_BASE_URL` 指向无效地址）时，演示可切换到截图/轨迹兜底，README 已知边界补充该备用路径说明 |
