# Google Gemini API 定价（免费层与付费层）

来源: https://ai.google.dev/pricing
抓取日期: 2026-09-01

价格为每百万 token 美元，Paid tier（免费层有每分钟/每日请求限制，输出常被限制在 500-1000 token/请求）。

## Pro 系列（复杂推理，1M token 上下文）

| 模型 | 输入 | 输出 | 备注 |
|------|------|------|------|
| Gemini 3.1 Pro (Preview) | $2.00（>200K: $4.00） | $12.00（>200K: $18.00） | ≤32K 输出 $2/$12 |
| Gemini 2.5 Pro | $1.25（>200K: $2.50） | $10.00（>200K: $15.00） | |

## 长上下文计费规则

Pro 系列以 200K token 为界分段计价（超出部分加价）：3.1 Pro 输入 2→4 倍档、输出 12→18；2.5 Pro 输入 1.25→2.5、输出 10→15。

## 其他要点

- **上下文缓存**：隐式缓存命中 $0.075-0.25/M（各模型不同），显式缓存存储 $4.50/M token/小时
- **Batch API**：50% 折扣
- **Gemini Embeddings**：text-embedding-004 / gemini-embedding-001 免费层可用，付费 $0.15/M 输入
- Grounding with Search：$35/千次；图像生成、TTS、视频生成另有独立价格

## 现象与规律（选型视角）

- Flash-Lite 3.1（$0.25/$1.50）与 2.5 Pro（$1.25/$10）相差 5 倍输入、6.7 倍输出
- 3.7 Flash 的介绍价只有正价一半——**"介绍价过期"是动态定价的典型案例**，做成本测算必须记价格生效日期
- 2.5 Flash 关闭思考模式能便宜 3 倍（$2.50→$0.40 输出）——"思考开关"本身就是路由变量
