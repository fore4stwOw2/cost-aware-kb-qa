## 关键计费规则

- **推理 token（reasoning tokens）对 API 不可见，但占用上下文窗口并按输出 token 计费**——推理型模型的实际输出成本远高于可见回答长度
- 缓存输入约为原价的 10%（部分老模型为 50%）
- Web search 内置工具：$10/千次调用，检索到的内容 token 按模型输入价另计
- 文件检索（File search）存储：$0.10/GB/天（1GB 免费）；调用 $2.50/千次

## 现象与规律（选型视角）

- gpt-5 家族内部价差约 35 倍（nano 输入 $0.05 vs gpt-5.2 $1.75），输出价差 35 倍
- 输出/输入价比约 8 倍（5.2：14/1.75），推理型旗舰更高
- pro 级（gpt-5.2-pro $21/$168）与常规旗舰差 12 倍
